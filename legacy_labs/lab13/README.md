# MongoDB Lab 13

Hands-on MongoDB replica set deployment using Docker Compose and Kubernetes
StatefulSet. See the [Docker lab guide](./Lab-13.1-Docker/README.md) and
[Kubernetes lab guide](./Lab-13.2-Kubernetes/README.md).

## Quick start (Docker Compose)

From `Lab-13.1-Docker`, run:

```sh
./generate-keyfile.sh
docker compose up -d
docker compose ps
docker compose exec mongo1 sh -ec \
  'mongosh --quiet -u "$MONGO_INITDB_ROOT_USERNAME" -p "$MONGO_INITDB_ROOT_PASSWORD" --authenticationDatabase admin --eval "rs.status().members.map(m => ({name:m.name,stateStr:m.stateStr}))"'
```

The generator creates a private `.env` and a Kubernetes keyfile under the
ignored `secrets/` directory. Do not commit or publish either file.
